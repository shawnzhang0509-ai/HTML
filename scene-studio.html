Scene Trace

在本地仓库（如 D:\工作\HTML）git pull + npm run dev 打开本页。即梦出底图，你逐层描矢量，导出进 scene-config.ts。

  1. 导入底图，对齐地平线/构图
  2. 单层模式：从远到近拖绿点；点白色脊线或「添加峰点」模式加点
  3. 卷帘对比检查偏差
  4. 复制片段 → 粘贴进 lib/scene-config.ts

0 · 画布 viewBox

输入数字后点「应用」；不要用滚轮（易变成 8 万+）

底图尺寸：—

1 · 底图

底图已画进 SVG，与绿点同一坐标；改画布后点「1:1 贴合」

2 · 视图

3 · 当前层 · 峰点

绿点任意拖（x/y 相对画布 0–1，不限制高度）· Shift 只调 Y · 脊线加点 · 双击删

近/中/远 = 多个 layer，从最远层开始描，需要几层就点几次「新增」

4 · 导出

快捷键：A 添加峰点 · H 底图 · Esc 退出对齐
