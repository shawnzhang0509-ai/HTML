Scene Trace

在本地仓库（如 D:\工作\HTML）git pull + npm run dev 打开本页。即梦出底图，你逐层描矢量，导出进 scene-config.ts。

  1. 导入底图，对齐地平线/构图
  2. 对照描边可开单层模式只描当前层；仅矢量会始终叠全部层预览
  3. 卷帘对比检查偏差
  4. 复制片段 → 粘贴进 lib/scene-config.ts

0 · 画布 viewBox

输入数字后点「应用」；不要用滚轮（易变成 8 万+）

底图尺寸：—

1 · 底图

底图已画进 SVG，与绿点同一坐标；改画布后点「1:1 贴合」

2 · 视图

对照描边：整屏半透明底图 + 矢量，日常描峰点用这个。

3 · 当前层 · 峰点

点绿点选中（变白）→ Delete 或上方按钮删；至少保留 3 个点 · 双击绿点也可删

下面列表 = 全部山层；点一行选中，「删」只删该层（不是面片竖条）

    绘制顺序：列表越后越靠近镜头。近/中/远 = 多层叠放，不是一层一个峰。

    描形建议关面片，只留纯色块；每层 5~8 个主棱峰再开面片预览。面片是 low-poly 近似，追即梦照片别较真。

    4 · 存档

    用 npm run dev 打开时，保存/加载项目根目录的 scene-workbench.json

    「打开」= 读进画布 · 「指定保存路径」= 只告诉 Ctrl+S 写哪个文件，不会读取

    快捷键：Ctrl+S 保存 · Ctrl+Z 撤回 · Delete 删选中峰点
